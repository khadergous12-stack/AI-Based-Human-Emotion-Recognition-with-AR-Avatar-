PROJECT OVERVIEW

Understand facial expressions with AI

EmotiSense analyses a facial image or live camera frame and estimates one of seven expression classes using a trained Custom CNN.

01 / WORKFLOW

From image to insight

  1. 01Capture — upload an image or use the webcam.
  2. 02Analyse — detect and prepare the face.
  3. 03Predict — the CNN estimates seven expression classes.
  4. 04Review — view confidence and class probabilities.
02 / TECHNOLOGY

Built with computer vision and deep learning

Python, TensorFlow/Keras, FastAPI and OpenCV power the recognition workflow. MediaPipe provides the optional live facial-landmark overlay. Unity and Blender support the wider AR-avatar direction.

02 / PROJECT DIRECTION

Goals & Vision

The purpose, intended outcomes and future direction of the AI-Based Human Emotion Recognition with AR Avatar project.

◎
01 / CORE OBJECTIVE

Recognize facial expressions

Build a deep-learning system that classifies facial images into seven expression categories: angry, disgust, fear, happy, neutral, sad and surprise.

⌁
02 / REAL-TIME EXPERIENCE

Interactive analysis

Provide image upload and webcam-based analysis with visual feedback, confidence scores and class probability distribution.

✧
03 / AR AVATAR

Connect AI with AR

Explore how predicted facial expressions can be represented through an animated avatar and augmented-reality experience.

◇
04 / LEARNING OUTCOME

Integrate technologies

Bring together machine learning, computer vision, backend development and 3D/AR tools in a single academic project.

PROJECT VISION

From recognition to an interactive experience

Develop a connected platform where facial-expression classification can become an input for engaging visual and avatar-based experiences. The project treats model outputs as estimates, not as definitive statements about a person's feelings.
