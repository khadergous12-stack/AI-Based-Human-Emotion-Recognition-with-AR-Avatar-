# AI-Based Human Emotion Recognition with AR Avatar

## Project Overview

An AI-powered facial emotion recognition system
that uses Deep Learning and Computer Vision to
identify basic facial expressions and represent
them through interactive avatars and games.

## Emotion Categories

- Happy
- Sad
- Angry
- Neutral

## Main Modules

1. Face Detection
2. Image Preprocessing
3. Emotion Recognition
4. Emotion Classification
5. Website Development
6. Emotion-Based Games
7. Unity 3D Game
8. Android AR Avatar

## Technology Stack

- Python
- TensorFlow / Keras
- CNN
- OpenCV
- FastAPI
- HTML, CSS, JavaScript
- Unity
- Blender
- AR Foundation
